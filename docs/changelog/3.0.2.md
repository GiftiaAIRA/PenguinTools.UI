修复导出曲包后，游戏内乐曲播放约一分钟后突然没有声音的问题。已经导出的曲包请重新导出音频。

Fixes music in exported option bundles going silent about a minute into a song in game. Re-export the audio of existing option bundles.

## 修复 / Fixes

- ACB 中写入与实际 AWB 一致的 AFS2 头和 MD5 校验。此前 ACB 一直沿用模板 AWB 的头，声明的数据长度固定为 2,958,464 字节，游戏按该长度流式播放：3.0.1 以 384 kbps 编码时约 61 秒后无声，更早版本以 128 kbps 编码时超过约 3 分钟的乐曲会在 3 分钟左右无声\
  Write the generated AWB's AFS2 header and MD5 checksum into the ACB. The ACB previously kept the template AWB's header, which declares a fixed 2,958,464-byte stream; the game streams only that much, so audio stopped after about 61 seconds at the 384 kbps rate used by 3.0.1, and after about 3 minutes at the 128 kbps rate used by earlier versions
- HCA 改为 192 kbps，与游戏自带音频一致；旧版本生成的音频缓存会自动重建\
  Encode HCA at 192 kbps to match the game's audio assets; cached audio from earlier versions is rebuilt automatically

内置命令行工具更新为 3.1.3，包含上游 PenguinTools 3.1.3 的音频导出修复。

The bundled CLI is updated to 3.1.3 and includes the audio export fix from upstream PenguinTools 3.1.3.
