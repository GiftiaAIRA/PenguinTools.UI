The first release of PenguinTools Extend, based on Foahh's PenguinTools. Extend uses a separate app data directory and update channel. Select your game folder when you first open the app.

企鹅工具箱 Extend 的首个版本，基于 Foahh 的企鹅工具箱。Extend 使用独立的应用数据目录和更新渠道，首次打开时需要选择游戏文件夹。

## 谱面转换 / Chart conversion

- 读取 MGXC 或 UGC 时自动识别 Margrete 谱面变体\
  Detect Margrete chart variants when reading MGXC or UGC
- 在桌面应用中将 C2S 提取为 MGXC 或 UGC 时，程序会自动选择编辑器目标\
  In the desktop app, extract C2S to MGXC or UGC and let automatic mode select the editor target
- 命令行可用 `--editor-target legacy` 或 `--editor-target standard` 指定 Margrete 1.8 或 1.9 输出\
  In the CLI, use `--editor-target legacy` or `--editor-target standard` for Margrete 1.8 or 1.9 output
- 修复 Margrete 原生保存或导出后转回 C2S 时，部分谱面丢失独立 CHR 判定的问题\
  Preserve standalone CHR judgements when affected charts are saved or exported by Margrete and converted back to C2S

兼容性检查使用了 Margrete 1.8.0、1.9.3 和扩展版 2.4.0 的样本。部分物件受目标格式限制，旧式 Bézier 曲线和带独立判定点的 AIR-CRUSH 存在导出限制。扩展谱中途切换有无连线的 SLIDE 转为 C2S 时会拆成多条，起点和中间判定数可能变化，游戏内判定数尚未实测。更换格式时请保留原谱。详见 [转谱说明](https://github.com/GiftiaAIRA/PenguinTools/blob/main/docs/chart-conversion.md)。

Compatibility checks used samples from Margrete 1.8.0, 1.9.3, and extended Margrete 2.4.0. Some features have target format limits, including legacy Bézier curves and AIR-CRUSH with explicit judgement points. An extended-chart SLIDE that switches its line partway is split into separate SLIDEs in C2S, which can change start and step judgement counts; in-game counts are not yet verified. Keep the original chart when switching formats. See the [chart conversion guide](https://github.com/GiftiaAIRA/PenguinTools/blob/main/docs/chart-conversion.md).

  Verify copied conversion-cache files before replacing existing outputs
